# Бот «Шкільний Слухач» — для гри «Жахлива школа»

Цей Python-бот приймає ідеї та повідомлення про баги, присвоює кожному повідомленню номер, зберігає їх у SQLite і дає розробнику кнопки для перегляду, обробки або видалення повідомлень.

## Важливо
Це готовий **код проєкту**, але його ще потрібно підключити до Telegram через токен BotFather і запустити на комп'ютері або сервері. Сам ZIP-файл не можна просто завантажити в канал і отримати працюючого бота.

## 1. Створи бота в Telegram
1. Відкрий Telegram і знайди `@BotFather`.
2. Надішли `/newbot`.
3. Вигадай назву, наприклад `Шкільний Слухач`.
4. Вигадай username, який закінчується на `bot`, наприклад `ShkilnyiSlukhachBot` (якщо вільний).
5. BotFather видасть токен. **Не публікуй токен і не надсилай його нікому.**

## 2. Дізнайся свій Telegram ID
Відкрий у Telegram бота на кшталт `@userinfobot` і подивись свій числовий ID. Впиши його як `ADMIN_ID`.

## 3. Встанови Python та бібліотеку
Потрібен Python 3.10 або новіший. У папці з файлами виконай:

```bash
pip install -r requirements.txt
```

## 4. Задай змінні та запусти

### Windows PowerShell
```powershell
$env:BOT_TOKEN="ВСТАВ_ТОКЕН_ВІД_BOTFATHER"
$env:ADMIN_ID="ТВІЙ_ЧИСЛОВИЙ_ID"
python bot.py
```

### Linux / macOS
```bash
export BOT_TOKEN="ВСТАВ_ТОКЕН_ВІД_BOTFATHER"
export ADMIN_ID="ТВІЙ_ЧИСЛОВИЙ_ID"
python3 bot.py
```

Не додавай лапки навколо числового ID всередині значення, крім синтаксису команди вище. Не публікуй токен.

## 5. Як користуватися
- Учасник відкриває бота й натискає `/start`.
- Обирає «Повідомити про баг», «Запропонувати ідею», «Запропонувати нову функцію» або «Написати розробнику».
- Пише текст і за бажанням додає фото, відео або файл.
- Натискає «Надіслати сповіщення». Бот підтверджує надсилання та показує номер, наприклад `№1`, `№2`, `№3`.
- Розробник відкриває бота зі свого Telegram-акаунта й натискає `/start`. У меню для нього є кнопка «Перевірити сповіщення».
- У списку можна вибрати номер, прочитати повідомлення, відкрити вкладення, натиснути «Обробити» або видалити сповіщення.

## Що означає «Обробити»
Ця кнопка позначає повідомлення як розглянуте. Вона **не змінює гру автоматично** — розробник сам вирішує, чи реалізувати ідею або виправити баг.

## Зробити бота доступним із каналу
1. Скопіюй username створеного бота.
2. У публікації Telegram-каналу додай посилання `https://t.me/ТВІЙ_USERNAME_БОТА`.
3. Закріпи цю публікацію, наприклад: «Є ідея або знайшов баг? Напиши нашому боту».

## Зберігання
Повідомлення зберігаються у файлі `school_feedback.sqlite3` у папці запуску. Для постійної роботи потрібен комп'ютер або сервер, який не вимикається. Зроби резервну копію цього файлу час від часу.
